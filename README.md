# متجر عُدّة

Static store site (GitHub Pages). Orders are sent to the store's WhatsApp; there is no backend.

- `index.html` — the store. Settings (`CONFIG`: WhatsApp number, delivery fee) are at the top of the main script.
- `products.js` — product list: `[id, name, price, originalPrice, category, inStock, photoPath]`.
- `logo.svg` — logo and favicon.
